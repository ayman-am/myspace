# MySpace

**مكان واحد خاص لصورك وملفاتك ونصوصك — على جوالك ولابتوبك، ومتزامن بينها.**

[English](README.md) · رخصة MIT

---

معظم تطبيقات التخزين مبنية للفرق: مجلدات مشتركة، دعوات، تعليقات، وباقات بعدد المقاعد. أنت على الأغلب كنت تريد شيئًا أبسط: تفتح رابطًا من أي جهاز، وتلقى أغراضك في مكانها.

لهذا MySpace أحادي المستخدم بالتصميم. تنشئ حسابًا واحدًا، ويتوقف التسجيل فورًا بعده. لا أحد يستطيع الانضمام، ولا شيء عام، ولا يوجد جدول منشورات. خزانة شخصية، لا شبكة اجتماعية.

## ما الذي يفعله

ارفع من منتقي الملفات، أو اسحب وأفلت، أو اكتب نصًا مباشرة. ثم شاهده يظهر على جهازك الآخر — غالبًا في أقل من ثانية ودون تحديث الصفحة.

- صور، PDF، ملفات مضغوطة، صوت — أي ملف حتى 50 ميغابايت
- حتى 20 ملفًا في الدفعة الواحدة، مع شريط تقدم يعكس الرفع الحقيقي
- النصوص نوع محتوى مستقل، لا حيلة ملتوية لتمرير شيء آخر
- معاينة الصور داخل الصفحة، وتنزيل بالاسم الأصلي للملف
- واجهة عربية من اليمين إلى اليسار، وضع داكن، وتعمل جيدًا من متصفح الجوال

## وما لا يفعله

لا دردشة، لا تعليقات، لا روابط مشاركة، لا مستخدمين متعددين، ولا ذكاء اصطناعي. لا شيء يحتاج سياسة إشراف أو شروط استخدام طويلة.

إن لم يكن الأمر متعلقًا بحفظ أغراضك في مكان واحد، فهو خارج نطاق المشروع.

## كيف بُني

- **الواجهة:** React 19 + TypeScript + Vite، والتنسيق بـ Tailwind CSS 4
- **البيانات:** Supabase Postgres مع تفعيل RLS
- **الملفات:** Supabase Storage، وعاء خاص، وروابط موقّعة فقط
- **التحديث الفوري:** Supabase Realtime (Postgres changes)
- **الاستضافة:** Vercel، عبر سير GitHub Actions الموجود في المستودع

## شغّل نسختك

المدة حوالي عشر دقائق، وكل ما هنا يعمل على الخطط المجانية.

1. أنشئ مشروعًا على [supabase.com](https://supabase.com).
2. افتح **SQL Editor**، والصق كامل ملف [`supabase/setup.sql`](supabase/setup.sql)، ثم شغّله.
   ينشئ الجدول والسياسات والوعاء الخاص والـ Realtime وقفل الحساب الواحد.
3. انسخ `Project URL` ومفتاح `anon` من **Project Settings → API**، ثم:

   ```bash
   cp .env.example .env
   npm install
   npm run dev
   ```

4. افتح التطبيق وأنشئ حسابك. أول حساب، والحساب الوحيد — بعدها يُغلق التسجيل.

**النشر:** استخدم زر Vercel أدناه، أو ادفع الكود إلى GitHub ودع السير الجاهز يبني المشروع وينشره.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/aymanjrmh/myspace&env=VITE_SUPABASE_URL,VITE_SUPABASE_ANON_KEY)

> النسخة الحيّة على https://myspace-coral.vercel.app هي مساحة صاحب المشروع الشخصية، والتسجيل فيها مغلق عن قصد. انشر نسختك لتجربته.

## الأمان باختصار

التفاصيل الكاملة، والإعدادات التي يشغّلها صاحب المساحة فقط، في [SECURITY.md](SECURITY.md).

- كل صف في الجدول مربوط بـ `auth.uid()` مع تفعيل RLS — لا يمكن قراءة أو تعديل بيانات مستخدم آخر حتى بمفتاح الـ anon العام.
- الوعاء خاص. كل عرض أو تنزيل يمرّ عبر رابط موقّع ينتهي بعد ساعة.
- مسارات التخزين إنجليزية (`{userId}/{uuid}/{uuid}.{ext}`)، والاسم الأصلي محفوظ في قاعدة البيانات. هذا التفصيل موجود لأن التخزين يرفض أسماء الملفات العربية أو التي فيها مسافات.
- محفّز في قاعدة البيانات (`enforce_single_user`) يرفض أي حساب ثانٍ.
- الواجهة تحمل مفتاح anon القابل للنشر فقط. لا وجود لمفتاح `service_role` في أي ملف.

## إعدادات ستريد تغييرها على الأغلب

| الإعداد | القيمة الافتراضية | مكان التغيير |
|---|---|---|
| الحد الأقصى للملف | 50 ميغابايت | `supabase/setup.sql` و `src/lib/supabase.ts` |
| الملفات في الدفعة | 20 | `src/lib/api.ts` |
| صلاحية رابط التوقيع | ساعة | `src/lib/api.ts` |

## خريطة المشروع

```
src/App.tsx            الجلسة، الحالة، الرفع، قناة Realtime
src/components/        شاشة الدخول، الهيدر، منطقة الرفع، البطاقات، المعاينة، نافذة النص
src/lib/api.ts         رفع / توقيع / تنزيل / حذف، ومفاتيح التخزين
supabase/setup.sql     الجدول، RLS، الوعاء، Realtime، قفل الحساب الواحد
.github/workflows/     النشر على Vercel مع كل دفعة
```
